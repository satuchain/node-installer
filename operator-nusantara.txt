Kami memerlukan bantuan Anda untuk menjalankan installer validator Satuchain di server Anda (217.15.167.165).

LANGKAH:
1. Buka VNC/Console panel Contabo untuk server Anda.
2. Jalankan:
   curl --ipv4 -fsSL https://raw.githubusercontent.com/satuchain/node-installer/main/install-validator.sh -o /tmp/install-validator.sh

3. Jika installer mendeteksi instalasi sebelumnya, pilih [Y] untuk Resume.
4. Setelah selesai, verifikasi:
   docker ps | grep satuchain-validator
   docker logs satuchain-validator --since 30m | tail -n 50
